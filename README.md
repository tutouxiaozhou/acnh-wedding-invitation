# 晴屿岛婚礼请柬

一份高辨识度的《集合啦！动物森友会》主题互动婚礼请柬概念稿。页面围绕 Dodo 航空登岛、西施惠的岛内广播、NookPhone 婚礼日程、岛屿地图、婚礼季与登岛护照展开。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 修改真实信息

婚礼姓名、日期、地点、流程和文案集中在 `src/App.tsx` 中；主视觉与响应式样式在 `src/styles.css` 中。
