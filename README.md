# 晴屿岛婚礼请柬

一份高辨识度的《集合啦！动物森友会》主题互动婚礼请柬概念稿。页面围绕 Dodo 航空登岛、岛内广播、NookPhone、里程任务、岛屿地图、婚礼季与登岛护照展开。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 修改真实信息

婚礼姓名、日期、地点、流程和文案集中在 `src/App.tsx` 中；主视觉与响应式样式在 `src/styles.css` 中。

## 素材说明

本项目是私人、非商业粉丝概念稿，与 Nintendo 无官方关联。游戏 Logo、角色、场景与婚礼季画面来自 Nintendo 官方网页，仅用于本地设计演示；每张位图均保留了来源元数据。
